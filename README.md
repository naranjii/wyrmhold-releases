# Wyrmhold

A minesweeper-roguelike: count the dark, wake the Wyrm.

**Download** the latest release for your system from [Releases](https://github.com/naranjii/wyrmhold-releases/releases/latest):

- Windows: `wyrmhold-<version>-windows.zip`, unzip, run `Wyrmhold.exe`.
- Linux: `wyrmhold-<version>-linux.zip`, unzip, run `./Wyrmhold.x86_64`.

The game updates itself on launch. Saves are kept between versions.
